# SafeJsonMapper examples

Maintained by Greelogix. Requires a Flutter SDK with Dart 3.11 or later.

Run the Flutter demo:

```sh
flutter pub get
dart run build_runner build
flutter run
```

Verify the generated mappings and demo UI:

```sh
flutter test
```

From the package root, run the standalone Dart example:

```sh
dart pub get
dart run build_runner build
dart run example/safe_json_mapper_example.dart
```
